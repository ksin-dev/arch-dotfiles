# Alacritty

Terminal emulator configuration.

## Files

- `alacritty.toml`: terminal settings

## Required

- `alacritty`
- `zsh`: configured as the login shell
- `JetBrainsMono Nerd Font`: configured font family

## Theme

`alacritty.toml` imports the shared generated theme file:

```toml
general.import = [ "~/.config/hypr/theme/alacritty.toml" ]
```

The imported file is generated by the repository root script:

```sh
./apply-theme.sh default
./apply-theme.sh graphite
```

This keeps Alacritty colors aligned with Hyprland and Quickshell.

## Install

From the repository root:

```sh
./install.sh alacritty
```

## Notes

The terminal launches:

```toml
shell = { program = "/bin/zsh", args = ["--login"] }
```
