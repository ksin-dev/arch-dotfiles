# Kitty

Kitty terminal configuration.

## Files

- `kitty.conf`: Kitty settings
- `theme.conf`: generated color theme from `apply-theme.sh`

## Required

- `kitty`

## Recommended

- A Nerd Font if prompt/icons are expected to render correctly
- `zsh` if using this terminal together with the zsh setup in this repo

## Theme

Kitty loads:

```text
~/.config/kitty/theme.conf
```

This file is generated by:

```sh
./apply-theme.sh default
./apply-theme.sh graphite
```

## Install

From the repository root:

```sh
./install.sh kitty
```

Reload Kitty config from an open Kitty window with:

```sh
kitty @ load-config
```

If remote control is disabled, restart Kitty instead.
